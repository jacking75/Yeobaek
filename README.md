# 여백 (Yeobaek)

> 광고가 아니라 여백을 남기는, 나만의 읽기용 브라우저

**여백**은 자주 읽는 블로그·기술 사이트를 방해 없이 읽기 위한 개인용 Windows
데스크톱 앱입니다. WebView2(Chromium)를 호스트하되, 네트워크 계층과 문서
초기화 시점을 앱이 직접 장악해 브라우저 확장이 구조적으로 할 수 없는 수준의
정리를 수행합니다.

- **플랫폼**: Windows 10 1809+ / Windows 11
- **런타임**: .NET 10 (LTS), WPF
- **엔진**: Microsoft Edge WebView2 Runtime (시스템 공유)

> 처음 쓰시나요? **[처음 사용하는 분을 위한 안내](#처음-사용하는-분을-위한-안내)** 부터 보세요.
> 설치부터 광고 숨기기, 리더 모드, 보관·검색까지 차례로 설명합니다.

---

## 왜 만드는가

범용 브라우저를 대체하려는 시도가 아닙니다. **읽기라는 단일 목적**으로 범위를
좁혔을 때만 얻을 수 있는 이점을 노립니다.

티스토리나 미디엄류의 자동 광고는 페이지 로딩이 끝난 뒤 스크립트가 본문
구조를 읽고 스스로 삽입합니다. 그래서 요소를 하나씩 찍어 숨기는 방식이 잘
듣지 않습니다. 호스트 앱은 페이지의 첫 스크립트보다 먼저 실행할 수 있으므로
삽입 시도 자체를 무산시킬 수 있습니다.

또한 MV3 확장에 걸려 있는 정적 규칙 3만 개·동적 규칙 5천 개 상한, 요청을
읽고 판단해 취소하는 방식의 금지, 스토어 심사로 인한 갱신 지연이 전부
사라집니다. 규칙은 내 SQLite 파일에 있고, 고치면 즉시 반영됩니다.

무엇보다 **관리 대상이 내가 실제로 읽는 도메인 수십 개로 한정**됩니다. 범용
차단기는 수만 개 사이트를 상대로 끝없는 군비 경쟁을 하지만, 여백은 전선이
좁아서 혼자서도 유지할 수 있습니다.

## 주요 기능

### 3중 방어 구조

| 층 | 수단 | 효과 |
|---|---|---|
| 1층 | `WebResourceRequested` 네트워크 차단 | 광고 요청을 아예 받지 않음. 원인 제거 |
| 2층 | `AddScriptToExecuteOnDocumentCreated` | 광고 SDK보다 먼저 개입. 삽입 자체를 무산 |
| 3층 | 리더 모드 (본문 추출) | 광고가 존재할 공간을 없앰. 최종 방어선 |

### 요소 선택기와 영구 기억

광고가 남아 있으면 `Alt+Shift+Z`로 선택 모드에 들어가 클릭합니다. 선택자가
도메인별로 SQLite에 저장되고, 다음 방문 시 페이지가 그려지기 전에 자동
적용됩니다. 개수 제한이 없습니다.

### 탭 브라우징과 링크 컨텍스트 메뉴

읽다가 참고 링크를 만났을 때 흐름이 끊기지 않도록 탭을 지원합니다.

- 링크 **우클릭** → `새 탭에서 열기`, `새 탭에서 열고 이동`, `새 창에서 열기`,
  `링크 주소 복사`, `나중에 읽기에 추가`
- `Ctrl+클릭` 또는 **가운데 버튼 클릭** → 백그라운드 새 탭 (`Ctrl+Shift+클릭` → 바로 이동)
- `Shift+클릭` → 새 창
- 페이지가 `window.open()`이나 `target="_blank"`로 창을 띄우려 하면 새 창이
  아니라 **새 탭으로 유도**해 팝업 광고가 별도 창으로 뜨는 것을 막습니다
- 사용자 조작 없이 뜨는 팝업은 막고, 알림 줄의 `열기`로 직접 열 수 있게 합니다

### 읽기 경험

렌더링된 페이지에서 본문만 추출하는 리더 모드(`Ctrl+R`), 본문 폭·서체·행간·테마
조절(`settings.json`), 시스템 설정을 따르는 다크 모드, 한글 줄바꿈 품질
(`word-break: keep-all`), 나중에 읽기 목록.

### 오프라인 보관과 전문 검색

읽던 글에서 `Ctrl+S`를 누르면 본문과 이미지를 PC에 저장합니다. 보관본은 인터넷 없이도
열리고, 원문이 지워지거나 바뀌어도 남습니다. 보관함(`Ctrl+Shift+F`)에서 제목·본문으로
찾을 수 있습니다(SQLite FTS5). 한국어는 조사가 붙거나 붙여 쓴 말이 많아 낱말 중간도 찾으며,
"검색"처럼 두 글자로도 찾습니다. 띄어 쓴 낱말은 모두 들어간 글만 보여 줍니다.

### 1. 설치하고 실행하기

아직 설치 파일을 따로 배포하지 않으므로, 소스를 받아 한 번 빌드해서 씁니다. 처음 한 번만 하면 됩니다.

1. **.NET 10 SDK 설치**
   [dotnet.microsoft.com/download](https://dotnet.microsoft.com/download) 에서 **.NET 10.0 SDK (Windows x64)** 를
   받아 설치합니다. 빌드에는 SDK 가 필요합니다(실행만 할 때는 Desktop Runtime 으로 충분합니다).
2. **소스 받기**
   [github.com/jacking75/Yeobaek](https://github.com/jacking75/Yeobaek) 에서 초록색 **Code → Download ZIP** 으로 받아
   압축을 풉니다. Git 을 쓴다면 `git clone https://github.com/jacking75/Yeobaek.git` 도 됩니다.
3. **빌드**
   압축을 푼 폴더(`README.md` 가 있는 곳)의 빈 곳을 **Shift+우클릭 → 터미널에서 열기**(또는 PowerShell 창 열기)
   한 뒤 아래를 입력합니다. `경고 0개, 오류 0개` 또는 `Build succeeded` 가 나오면 끝입니다.

   ```powershell
   dotnet build
   ```

4. **실행**
   `bin\Debug\Yeobaek.exe` 를 두 번 누릅니다. 자주 쓴다면 실행 중에 작업 표시줄 아이콘을 우클릭해
   **작업 표시줄에 고정** 해 두세요.

> **WebView2 런타임**은 Windows 11 과 대부분의 Windows 10 에 이미 들어 있습니다. 없으면 여백이 시작할 때
> 설치 주소와 함께 알려 주니, 설치한 뒤 다시 실행하면 됩니다.
>
> 다른 폴더로 옮겨 쓸 **실행 파일 하나**가 필요하면 [빌드와 실행](#빌드와-실행)의 `dotnet publish` 명령을 쓰세요.

### 2. 화면 둘러보기

```
┌───────────────────────────────────────────────────────────────────────┐
│ [ 글 제목 ×][ 다른 탭 × ]                                         [+] │ ← 탭 줄
│  ←  →  ⟳  [ 주소를 입력하거나 검색하세요     ] [차단 12] 리더 목록 보관함 ⋯ │ ← 도구 모음
│                                                                       │
│                             웹 페이지                                  │
│                                                                       │
│ 나중에 읽기에 추가했습니다.                               [목록 보기] × │ ← 알림 줄
└───────────────────────────────────────────────────────────────────────┘
```

| 자리 | 하는 일 |
|---|---|
| **탭 줄** | 연 페이지들. `×` 로 닫고, 오른쪽 `+` 로 새 탭을 엽니다. 탭을 **가운데 버튼으로 눌러도** 닫힙니다. |
| **← → ⟳** | 뒤로 · 앞으로 · 새로 고침 |
| **주소창** | 주소나 검색어를 넣고 `Enter` |
| **방패 `차단 12`** | 이 페이지에서 막은 광고 요청 수. 누르면 이 사이트를 **예외 사이트**(광고 허용)로 바꿉니다 → [4번](#4-광고-줄이기) |
| **리더** (펼친 책 모양) | 본문만 보여 주는 리더 모드 켜기/끄기 → [5번](#5-편하게-읽기--리더-모드) |
| **목록** (줄 모양) | 나중에 읽기 목록 → [6번](#6-나중에-읽기) |
| **보관함** (책장 모양) | 보관한 글 찾기 → [7번](#7-보관하고-다시-찾기) |
| **⋯** (메뉴) | 모든 기능과 단축키, 설정 파일·데이터 폴더 열기 |
| **알림 줄** | 창 아래에 잠깐 나타났다 사라집니다. 마우스를 올려 두면 사라지지 않고, `되돌리기`·`열기` 같은 버튼이 붙기도 합니다. |

새 탭을 열면 가운데에 자주 쓰는 단축키와 **나중에 읽을 글**, **보관한 글** 버튼이 나옵니다.
버튼 위에 마우스를 올리면 설명과 단축키가 보입니다.

### 3. 웹 페이지 보기 기본

- **주소로 가기·검색**: 주소창을 누르거나 `Ctrl+L` → `example.com` 같은 주소나 검색어를 넣고 `Enter`.
  검색은 기본으로 Google 을 씁니다([8번](#8-설정-바꾸기)에서 바꿀 수 있습니다).
- **탭**: 새 탭 `Ctrl+T` · 닫기 `Ctrl+W` · 다음/이전 탭 `Ctrl+Tab` / `Ctrl+Shift+Tab` · 방금 닫은 탭 다시 열기 `Ctrl+Shift+T`
- **새 창**: `Ctrl+N`
- **링크 여는 방법**

  | 이렇게 누르면 | 이렇게 열립니다 |
  |---|---|
  | 그냥 클릭 | 지금 탭에서 |
  | `Ctrl+클릭` 또는 **가운데 버튼** | 뒤쪽 새 탭에서 (읽던 글을 계속 읽을 수 있어요) |
  | `Ctrl+Shift+클릭` | 새 탭을 열고 바로 이동 |
  | `Shift+클릭` | 새 창 |
  | **우클릭** | 메뉴: 새 탭에서 열기 · 새 창에서 열기 · 링크 주소 복사 · 나중에 읽기에 추가 |

- **글자 크게/작게**: `Ctrl+마우스 휠`, 또는 `Ctrl` + `+` / `-`, 원래대로 `Ctrl+0`
- **페이지에서 찾기**: `Ctrl+F` · **새로 고침**: `F5` (`Ctrl+R` 은 리더 모드입니다)
- 사이트가 몰래 띄우는 **팝업은 자동으로 막습니다**. 필요한 팝업이었다면 알림 줄의 `열기` 를 누르세요.

### 4. 광고 줄이기

**그냥 읽으면 됩니다.** 여백은 알려진 광고를 페이지가 그려지기 전에 막습니다.
도구 모음의 방패 `차단 12` 가 지금 페이지에서 막은 광고 요청 수입니다.

**남은 광고를 직접 숨기기**

1. `Alt+Shift+Z` 를 누릅니다. 광고 위에서 **우클릭 → 이 영역 광고 숨기기** 를 골라도 됩니다.
2. 마우스를 움직이면 **주황색 테두리**가 따라다닙니다. 숨길 광고에 맞추세요.
   화면 아래에 선택자(어떤 요소인지)가 표시됩니다.
3. 테두리가 광고 일부만 감싸면 `↑` 로 바깥 영역까지 넓히고, 너무 크면 `↓` 로 좁힙니다.
4. **클릭**(또는 `Enter`)하면 바로 사라지고, 다음부터 이 사이트에서는 페이지가 뜨기 전에 자동으로 숨깁니다.
   그만두려면 `Esc` 나 우클릭.
5. 잘못 숨겼다면 알림 줄의 **되돌리기**. 시간이 지났다면 **⋯ → 이 사이트 규칙 관리** 에서 골라 지웁니다.

> 본문까지 사라지지 않도록, 테두리가 광고만 감쌀 때 클릭하세요. 규칙 관리 창에서는 선택자를 직접 넣어
> 추가하거나 **모든 사이트에 적용** 할 수도 있습니다.

**좋아하는 사이트는 광고를 허용하기 (후원)**

방패 버튼을 누르거나 `Alt+Shift+A` 를 누르면 방패가 주황색 **예외 사이트** 로 바뀌고, 이 사이트에서는 광고를
막지 않습니다. 다시 누르면 원래대로 막습니다. 광고 차단 때문에 사이트가 제대로 동작하지 않을 때도 이렇게 하세요.

**차단 목록 직접 고치기 (선택)**

**⋯ → 차단 목록 편집 (blocklist.txt)** 을 누르면 메모장이 열립니다. 기본 목록은 여백에 들어 있고,
이 파일에는 **더하거나 뺄 항목만** 한 줄에 하나씩 적습니다. 저장하고 여백 창으로 돌아오면 바로 적용됩니다.

```
# 이 호스트와 그 하위 도메인을 막기
ads.example.com
# 주소 경로에 /banner/ 가 들어가면 막기
/banner/
# 기본 목록에 있는 항목을 막지 않기 (앞에 !)
!static.criteo.net
```

### 5. 편하게 읽기 — 리더 모드

- `Ctrl+R` 또는 도구 모음의 **리더** 버튼을 누르면 광고·메뉴·댓글 없이 **본문만** 넉넉한 여백으로 보여 줍니다.
  다시 누르면 원래 페이지로 돌아갑니다.
- 리더 모드에서도 주소창에는 원래 글 주소가 보이고, 제목 아래 **원문 보기** 로 원래 페이지를 열 수 있습니다.
- 쇼핑·SNS·검색 결과처럼 "글"이 아닌 페이지는 본문을 찾지 못합니다. 그럴 때는 원래 화면을 그대로 두고
  알림으로 알려 줍니다.
- 글자 크기·줄 간격·본문 폭·어두운 화면은 [8번](#8-설정-바꾸기)에서 바꿉니다.

### 6. 나중에 읽기

- **지금 보는 글**: `Ctrl+D` · **링크**: 우클릭 → **나중에 읽기에 추가**
- 도구 모음의 **목록** 버튼으로 목록을 엽니다. 글을 두 번 누르면 새 탭에서 열리고 **읽음** 으로 표시됩니다.
- 위쪽 **읽지 않은 글만** 을 끄면 읽은 글도 보입니다. `읽음 / 안 읽음`, `삭제` 버튼으로 정리하세요.

### 7. 보관하고 다시 찾기

- **보관하기**: 읽던 글에서 `Ctrl+S` (또는 **⋯ → 이 글 보관하기**). 본문과 **이미지까지 PC 에 저장**하므로
  인터넷이 없어도, 원래 글이 지워지거나 바뀌어도 그대로 읽을 수 있습니다. 이미지가 많으면 몇 초 걸립니다.
- **찾기**: `Ctrl+Shift+F` 또는 도구 모음의 **보관함** 버튼 → 검색 칸에 낱말을 넣으면 제목과 본문에서 찾습니다.
  - 여러 낱말을 띄어 쓰면 **모두 들어간 글만** 보여 줍니다.
  - "검색"처럼 **두 글자**도 되고, "커서"로 "커서를", "검색"으로 "전문검색" 처럼 **낱말 중간**도 찾습니다.
  - 검색 칸을 비우면 보관한 글이 모두 최근 순으로 보입니다.
- **보관본 열기**(인터넷 없이 열림) · **원문 열기**(지금의 최신 글) · **삭제**(저장한 이미지까지 지움) 중에 고릅니다.
- 같은 글을 다시 `Ctrl+S` 하면 최신 내용으로 바꿔 저장합니다.

### 8. 설정 바꾸기

**⋯ → 설정 파일 편집 (settings.json)** 을 누르면 메모장이 열립니다. 고쳐서 저장한 뒤 여백 창으로 돌아오면
적용됩니다(리더 모드 모양은 다음에 리더 모드를 켤 때부터). `//` 뒤는 설명이며 파일에 넣어도 됩니다.

```jsonc
{
  "startPage": "about:blank",                          // 새 창·새 탭의 첫 페이지. 예: "https://news.hada.io"
  "searchUrl": "https://www.google.com/search?q={0}",  // 검색 주소. {0} 자리에 검색어가 들어갑니다
  "reader": {
    "fontSizePx": 17,       // 글자 크기 (12 ~ 32)
    "lineHeight": 1.85,     // 줄 간격 (1.2 ~ 2.6)
    "maxWidthRem": 42,      // 본문 폭 (28 ~ 80)
    "fontFamily": "\"Pretendard\", \"Malgun Gothic\", system-ui, sans-serif",
    "theme": "system"       // system(Windows 설정 따름) · light(밝게) · dark(어둡게)
  }
}
```

- 네이버로 검색하려면: `"searchUrl": "https://search.naver.com/search.naver?query={0}"`
- 파일 내용이 잘못되면 알림으로 알려 주고 기본 설정으로 동작합니다. 파일을 지우면 다음 실행 때 기본값으로 다시 만들어집니다.

### 9. 문제가 생겼을 때

| 이런 경우 | 이렇게 해 보세요 |
|---|---|
| 시작하자마자 **WebView2 런타임을 찾을 수 없다**고 나온다 | 안내 창의 주소에서 **Evergreen 부트스트래퍼**를 받아 설치한 뒤 다시 실행 |
| 터미널에서 **`dotnet` 을 찾을 수 없다**고 나온다 | .NET 10 SDK 를 설치한 뒤 터미널을 **새로 열어** 다시 입력 |
| 사이트가 깨지거나 버튼이 눌리지 않는다 | ① 방금 숨긴 요소 때문이면 **⋯ → 이 사이트 규칙 관리** 에서 지우기 ② 아니면 방패 버튼으로 **예외 사이트** 지정 |
| "광고 차단 소프트웨어가 방해하고 있다"는 안내가 뜬다 | 사이트가 광고 차단을 알아챈 것입니다. 계속 보려면 그 사이트를 **예외 사이트**로 |
| 리더 모드가 켜지지 않는다 | 본문으로 인식할 글이 없는 페이지입니다. 원래 화면으로 보세요 |
| 보관본의 이미지 일부가 안 보인다 | 보관할 때 받지 못한 이미지입니다(알림에 개수가 나옵니다). 인터넷이 연결되면 보이며, 원문에서 다시 `Ctrl+S` 해도 됩니다 |
| 로그인이 유지되나요? | 네. 로그인 상태(쿠키)는 여백 전용 프로필(`%LOCALAPPDATA%\Yeobaek\WebView2`)에 남습니다. 비밀번호와 자동 완성 정보는 저장하지 않습니다 |
| 다른 PC 로 옮기고 싶다 | **⋯ → 데이터 폴더 열기** 에서 `rules.db`, `blocklist.txt`, `settings.json`, `archive` 폴더를 복사 |
| 이상하게 동작한다 | **⋯ → 데이터 폴더 열기** 의 `error.log` 에 기록이 남습니다. 문제를 알릴 때 함께 보내 주세요 |
| 지우고 싶다 | 여백 폴더와 `%LOCALAPPDATA%\Yeobaek` 폴더를 지우면 깨끗이 지워집니다 |

## 빌드와 실행

```bash
git clone https://github.com/jacking75/Yeobaek.git
cd Yeobaek
dotnet build                      # → bin\Debug\Yeobaek.exe
dotnet run --project src/Yeobaek
dotnet test                       # 단위 테스트 → bin\Debug\tests\
```

빌드 산출물은 저장소 루트의 `bin\<구성>\`에 모이며 `net10.0-windows` 같은 프레임워크
폴더는 만들지 않습니다(`Directory.Build.props`).

배포용 단일 실행 파일 (→ `bin\publish\Release\Yeobaek.exe`):

```bash
dotnet publish src/Yeobaek -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true
```

결과는 `Yeobaek.exe` 파일 하나(약 5MB)입니다. 네이티브 DLL(WebView2Loader, SQLite)과 디버그 기호도 그 안에
들어 있어, 이 파일만 복사해 쓰면 됩니다(대상 PC 에는 .NET 10 Desktop Runtime 이 필요합니다).

## 데이터 위치

```
%LOCALAPPDATA%\Yeobaek\
├─ rules.db          요소 숨김 규칙, 차단 예외 사이트, 나중에 읽기, 보관한 글 목록·검색 색인
├─ blocklist.txt     네트워크 차단에 더하거나('!'로) 뺄 항목 (기본 목록은 앱에 내장)
├─ settings.json     시작 페이지·검색 주소·리더 서체/행간/폭/테마
├─ reader\           리더 모드 페이지 (7일 지나면 지움)
├─ archive\          보관한 글 (글마다 index.html + images\, 보관함에서 지울 때까지 남음)
├─ error.log         예상하지 못한 오류 기록 (있을 때만)
└─ WebView2\         WebView2 사용자 프로필 (쿠키·로그인 세션)
```

`rules.db`와 `blocklist.txt`만 백업하면 다른 PC에서 그대로 복원됩니다. 보관한 글까지
옮기려면 `archive\` 폴더도 함께 복사하세요.
`blocklist.txt`와 `settings.json`은 메뉴(`⋯`)에서 바로 열 수 있고, 저장한 뒤 여백 창으로
돌아오면 다시 읽습니다.

## 알아둘 점

WebView2는 시스템의 Edge WebView2 런타임을 공유하므로, 배포물이 작고
Chromium 보안 패치는 런타임 갱신으로 따라옵니다. 다만 **정식 uBlock
Origin을 `AddBrowserExtensionAsync`로 넣어 쓰는 방식은 계획에 없습니다.**
WebView2는 Edge의 Manifest V2 정책을 물려받고, Edge는 2026년 8월부터 일반
사용자 대상 MV2 퇴출을 시작해 연내 마무리·기업 환경 2027년 초로 예고되어
있습니다. 여백의 차단은 확장이 아니라 호스트 코드가 담당합니다. (이 정책
일정은 이후 변경될 수 있으니 착수 전 최신 상태를 확인하세요.)

사이트가 HTML 구조를 바꾸면 저장한 선택자는 깨집니다. 클래스명이 난독화된
사이트에서는 `#id`나 `[data-*]` 속성을 기준으로 잡는 편이 오래 버팁니다.

여백은 의도적으로 **소수의 사이트만 상대하도록** 설계되었습니다. 대상 도메인을
넓히는 순간 혼자 감당할 수 없는 경쟁이 시작되므로, 목록을 작게 유지하는 것이
설계의 일부입니다. 평소 즐겨 읽어 도움을 받는 블로그를 규칙 예외로 두는
기능(`Alt+Shift+A`)도 넣어두었습니다.
