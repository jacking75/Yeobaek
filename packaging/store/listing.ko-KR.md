# 한국어 Store 등록 문구

예약한 앱 이름 `여백`을 네 언어의 Store 소개에 사용한다.

## 설명

여백은 블로그와 기술 문서를 읽는 데 집중하는 무료 Windows 브라우저다.

알려진 광고 요청을 줄이고, 남은 광고는 직접 선택해 숨길 수 있다. 리더 모드에서는 본문을 넉넉한 여백으로 읽는다. 나중에 읽기 목록에 주소를 모으고, 필요한 글과 이미지를 PC에 보관해 다시 읽을 수 있다.

주요 기능은 다음과 같다.

- 알려진 광고 요청 차단과 사이트별 광고 예외 설정
- 직접 선택한 영역을 숨기고 사이트별 규칙으로 기억
- 글꼴, 줄 간격, 본문 너비와 밝은·어두운 테마를 조절하는 리더 모드
- 탭과 새 창, 링크 우클릭 메뉴
- 나중에 읽기 목록
- 글과 이미지의 로컬 보관 및 저장된 글 검색
- 한국어, 영어, 일본어, 중국어 간체 화면 지원

보관한 글과 설정은 PC에 저장된다. 여백 개발자 서버에 동기화하지 않는다.
웹사이트 열기와 검색에는 인터넷 연결이 필요하다. 보관 시 내려받지 못한 이미지나 외부 콘텐츠는 오프라인에서 표시되지 않을 수 있다.
광고 차단과 본문 추출은 사이트 구조에 따라 다르게 동작한다.

앱은 무료이며 앱 내 결제나 유료 체험판을 제공하지 않는다.

## 이번 버전의 변경 사항

여백 0.1.0의 첫 Microsoft Store 배포다.

## 검색어

여백; 브라우저; 리더 모드; 광고 차단; 나중에 읽기; 오프라인 읽기; 글 보관
