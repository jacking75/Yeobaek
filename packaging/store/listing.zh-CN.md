# 简体中文 Store 介绍

## Description

여백 (Yeobaek) 是一款专注于阅读博客和技术文章的免费 Windows 浏览器。

它可以拦截已知的广告请求，并让您选择要隐藏的页面元素。阅读模式支持调整字体、行距、正文宽度和主题。您可以使用标签页和独立窗口，将链接加入稍后阅读列表，在本机保存文章和图片，并搜索已保存的文章。

界面支持韩语、英语、日语和简体中文。保存的文章和设置保存在您的电脑上，不会同步到开发者的服务器。

浏览网页和搜索需要网络连接。保存时未能下载的图片和外部内容可能无法离线显示。广告拦截和正文提取的效果取决于网站结构。

本应用免费，没有应用内购买或付费试用版。
