# 日本語 Store 紹介

## Description

여백 (Yeobaek) は、ブログや技術記事を読むための無料 Windows ブラウザーです。

既知の広告リクエストをブロックし、不要な要素を選んで非表示にできます。リーダーモードでは、フォント、行間、本文の幅とテーマを調整できます。タブや別ウィンドウ、後で読むリスト、記事と画像のローカル保存、保存した記事の検索に対応しています。

画面の言語は韓国語、英語、日本語、中国語（簡体字）に対応しています。保存した記事と設定は PC 内に保存され、開発者のサーバーへ同期しません。

閲覧と検索にはインターネット接続が必要です。保存時に取得できなかった画像や外部コンテンツはオフラインでは表示できない場合があります。広告ブロックと本文抽出の結果はサイトの構造により異なります。

アプリは無料で、アプリ内購入や有料試用版はありません。
